# radishes-unearthed-2025
Rainbow Radishes Source Code for 2025 Unearthed champion project

## Folder structure

| Name | Purpose |
|---|---|
| `helpers/` | Helper code to identify the global variables |
| `missions/` | Optional individual mission files in case we need to version |
| `python_runs/` | The run files coded as Python |
| `sparkruns/` | The Spark project files that are pasted in to Spike Prime and loaded into the programs as mission |
